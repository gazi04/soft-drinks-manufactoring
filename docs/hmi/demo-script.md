# Demo script – filler + syrup room + labeler + packer (about 25 minutes)

A fixed order for presenting the line: four PLCs (OpenPLC, one runtime per machine), one plant (the Python simulator drives all four) and one HMI (FUXA shows all four), working as one closed loop. **Rehearse it once before the presentation.**

What was checked when:
- **Filler** steps: all checked live with FUXA as the HMI in HMI stage 7.3 (`roadmap.md`, 2026-11-04).
- **Syrup room** steps: the scenarios on the real PLCs (`buffer_starved` and `level_sensor_stuck` by hand, 2026-11-13), the *Syrup room* screen with `cooling_failure` / `over_pressure` (S3, 2026-11-13), Line block, alarms and trends live on 2026-11-14; the two-machine script was rehearsed on 2026-11-15.
- **Labeler** steps: each screen in the browser with a fault scenario (L2–L6, 2026-11-19); the three-machine script was rehearsed once with FUXA as the only operator on 2026-11-19 (`roadmap.md`, "L7 as built").
- **Packer** steps: each screen in the browser with a fault scenario (P2–P6, 2026-11-23 / 24: `film_torn`, `palletizer_stopped`, `film_empty`, `sheet_dropped`, one oven warm-up); this four-machine script was rehearsed once with FUXA as the only operator on 2026-11-24 (`roadmap.md`, "P7 as built": the measured times below come from that run).

**Screens:** browser with FUXA (`http://localhost:1881`), one terminal with the simulator panel (at least 140×45). Optional: OpenPLC editor (filler `https://localhost:8443`, syrup room `https://127.0.0.2:8443`, labeler `https://127.0.0.3:8443`, packer `https://127.0.0.4:8443`) to show the ladder.

**Rule:** during the demo FUXA is the only operator (Start, Stop, Reset, mode, setpoints) for all four machines. Never run `tests/hmi.py` or a `tests/test_*.py` script at the same time. The panel's hints name `tests/hmi.py` (written for test runs): during the demo press the same buttons in FUXA's header.

**Which machine a button acts on:** header row 1 shows all four machines (chip = state, mode and PLC link; click = its screen) and one E-stop segment per PLC; row 2 (Start / Stop / Reset, Auto / Manual / Stop, alarm chips) belongs to **one** machine. On Line, Alarms and Trends the four buttons on the left of row 2 (*Filler* / *Syrup* / *Labeler* / *Packer*) pick it; on the *Filler*, *Syrup room*, *Labeler* and *Packer* screens it is that machine.

**One scenario at a time:** the panel has one scenario slot; **Run** replaces a scenario that is still running, which then stops where it was (e.g. `palletizer_stopped` replaced early leaves the palletizer stopped). Wait until the scenario status in the panel says *done*.

## 1. Before the presentation (15 min before)

1. Start the stack (repo root): `docker compose up -d`
2. Pre-demo check: `cd simulator && uv run python tests/demo_check.py`. If D2 says *Modbus server is OFF* or *no compiled program* (after a container re-creation or a laptop suspend): OpenPLC Editor, upload `plcs/filler` (device `localhost`), `plcs/syrup` (device `127.0.0.2`), `plcs/labeler` (device `127.0.0.3`) and `plcs/packer` (device `127.0.0.4`).
3. Start the simulator with its panel: `cd simulator && uv run simulator` (drives all four PLCs).
4. FUXA **Alarms**: **Ack** every row, then **Reset** once per machine (picker *Filler*, *Syrup*, *Labeler*, *Packer* in row 2, **Reset** each). A fresh simulator start always leaves `Alm_CommLost` latched on **all four** machines. One Reset per machine is enough, also after a FAULT.
5. `uv run python tests/demo_check.py` again → **0 FAIL** (a WARN tells you the fix).
6. Panel defaults: tab `1 Filler`: **Supply /min** `30`, **Fill flow** `100`, switches **Supply paused** OFF, **Product available** ON, **E-stop** OFF. Tab `2 Syrup room`: no fault switch ON. Tab `3 Labeler`: no fault switch ON, **Heartbeat** ON. Tab `4 Packer`: no fault switch ON, **Palletizer running** ON, **Heartbeat** ON.
7. FUXA, per machine with the picker, **from the end of the line backwards**: **Packer** → **Auto**, **Start**; **Labeler** → **Auto**, **Start**; **Syrup** → **Auto**, **Start**; **Filler** → **Auto**, **Start**. The packer first heats its oven (WARM_UP, about a minute), the labeler its glue (under a minute): started first, both are ready before the first bottles reach them, so nothing turns orange (Blocked) at the start.
8. Let it run until the first pack has left the oven (**Packs** ≥ 1 on the Line view) and **one syrup batch** is done, so all four Trends views have curves.
9. Close everything else; set the browser zoom so the whole Line view fits.

## 2. The demo

| # | Time | Do | Show / say |
|---|---|---|---|
| 1 | 1 min | FUXA **Line** view | The architecture in one sentence: *each machine has its own PLC, the simulator is the factory, FUXA is the operator – they only talk through the PLCs' memory over Modbus TCP; the PLCs never read each other.* Point at the four real machines (coloured by their state), the grey stand-ins (blow moulder at the start, palletizer at the end), C1 / C2 / C3, and the product pipe from the syrup room into the filler. *A conveyor's full sensor is wired to the machine upstream of it; the machine downstream drives the belt (C2 turns with the labeler's motor output, C3 with the packer's).* |
| 2 | 1 min | **Filler** chip → **Filler** view | Bottles step along C1, the filler is green. The pockets (rinse, fill, cap), the fill bar climbing to the 500 ml setpoint, the lamps of the outputs. *Indexing machine: all stations work in parallel (WORK), then the belt moves every bottle one station (INDEX).* |
| 3 | 2 min | **Syrup room** chip → **Syrup room** view | One batch: DOSE_WATER → DOSE_SYRUP (ratio 5.5 : 1 → *Syrup per batch*) → MIX → COOL → CARBONATE → TRANSFER. The pipes colour while their pump or valve runs; temperature in °C and pressure in bar (the PLC keeps 0.1 °C / 0.01 bar integers, FUXA scales). *The buffer is filled batch by batch; the filler takes product from it continuously.* Point at the note under the buffer: *each 0.5 L bottle takes 15 L – the simulator compresses time ×30, otherwise one batch would last hours; the PLCs don't know about it.* |
| 4 | 1.5 min | **Labeler** chip → **Labeler** view | One bottle: the gate lets it into the pocket, the bell comes down (CLAMP), the web feeds one label up to its registration mark (WRAP, the web turns white), the turntable presses it on for two turns (PRESS), the pusher sends it onto C3. The pocket shows *bottle → labelling → labelled*. The melt tank: glue at 170 °C, the red tick is the 200 °C over-temperature limit; the heater switches itself on and off in a narrow band (*hysteresis*, also in Manual). *Labelled* counter with its own **Reset counter** (`Cmd` = 4; Reset in the header keeps the count). |
| 5 | 2 min | **Packer** chip → **Packer** view | Two sequencers in parallel (*collation* and *wrap*, each with its own step on the screen): the gate counts six bottles onto the table, the pusher pushes the group onto the wrap belt; the film feed pushes one sheet up out of the slot (counted in 50 mm pulses up to *Film length*), the knife cuts it, the pack runs over it and the **wrap bar** turns once around it; the shrink **oven** (heater, blower, airflow lamp) shrinks the film, finished packs land on the outfeed table. The oven bar: the red tick is the 230 °C over-temperature limit; the heater keeps the air just under its setpoint (*hysteresis*), **only in Auto**, and the blower runs on 30 s after the oven is switched off (*TOF*). *Packs* counter with **Reset counter** (`Cmd` = 4). *Interlocks: the wrap bar beats the film feed beats the knife.* |
| 6 | 1 min | Header **Trends**, picker **Packer**, then **Labeler**, **Syrup**, **Filler** | Packer: the oven warm-up to its window, then the heater's saw tooth; packs climbing. Labeler: the warm-up from room temperature to the setpoint at the start, then the heater's saw tooth; labelled bottles climbing. Syrup room: mixing level in two slopes (water, then syrup), temperature down, pressure up to its setpoint. Filler: one fill ramp per bottle. *FUXA logs these values in its own history, already scaled to °C / bar.* |
| 7 | 3 min | Panel: scenario **`palletizer_stopped [packer]`** → Run, FUXA **Line** – wait until the panel says *done* | The palletizer stands: the outfeed table fills, the packer turns **orange (Blocked)** with a pack waiting in READY; C3 fills slot by slot and the **labeler** turns orange, then C2 and the **filler** – the blockage travels upstream through the whole line, machine by machine, without a fault (rehearsal: packer Blocked 105 s after Run, the labeler 78 s later, the filler 42 s later; all running again 17 s after the warning). After 2 min Blocked the packer's warning *Outfeed blocked* (yellow, low) comes, the palletizer runs again and every machine continues **by itself**. |
| 8 | 2 min | Panel: scenario **`buffer_starved [syrup]`** → Run, FUXA **Line** | The filler draws faster than the syrup room can mix: the buffer runs dry, the pipe turns grey, *no product*, the filler turns **yellow (Starved)** – **no alarm**, nobody did anything wrong (rehearsal: Starved 134 s after Run). The next batch reaches the buffer (34 s later): product back, the filler continues **by itself**. *The only signal between the two PLCs is `Product_Available` – a hardwired handshake, emulated by the simulator.* |
| 9 | 2 min | Panel: scenario **`level_sensor_stuck [syrup]`** → Run (it waits for the next DOSE_WATER – right after step 8 the buffer is low, so that comes at once), FUXA **Syrup room** | The level sensor freezes while the water pump runs; the tank keeps filling. The **high-high switch** (a separate hardware switch, the backup) trips `Alm_Overflow`: **red (Fault)**, every pump off. **Alarms**: the *Machine* column says *Syrup room*; one list for the whole line. When the panel says the tank is drained: **Ack**, **Reset** (picker *Syrup*), **Start**. |
| 10 | 1.5 min | Panel: scenario **`web_torn [labeler]`** → Run, FUXA **Labeler** | The label web tears between two bottles. In WRAP the PLC waits for the registration mark; after 5 s: **red (Fault)**, `Alm_LabelTimeout`, everything off, the heater too (the glue cools slowly, about 5 °C in 20 s, so reset soon). *A watchdog timer on a sensor that must come.* When the panel says *press Reset + Start*: **Reset**, **Start** in the Labeler screen's header – web threaded again, the bottle in the pocket gets its label. |
| 11 | 1.5 min | Panel: scenario **`sheet_dropped [packer]`** → Run, FUXA **Packer** | At the cut the sheet falls out of the slot. In READY the PLC checks that a sheet stands in the slot; after 1 s without one: **red (Fault)**, `Alm_FilmFault`, both sequencers FAULT, everything off except the **oven blower on its run-on** (cooling first) (rehearsal: FAULT 21 s after Run, the next pack 11 s after Start, no jam upstream). When the panel says *press Reset + Start*: **Reset**, **Start** in the Packer screen's header – the sheet put back by hand is used, no second sheet is fed. |
| 12 | 1.5 min | Panel: scenario **`index_jam [filler]`** → Run, FUXA **Filler** then **Alarms** | The belt motor is ON but the bottles don't move. After 5 s: **red (Fault)**, `Alm_IndexJam`. *A watchdog timer: the cam S8 must come within 5 s.* When the panel says *press Reset + Start*: **Ack**, **Reset**, **Start** (picker *Filler*). No bottle is lost. |
| 13 | 1.5 min | Panel: scenario **`e_stop [filler]`** → Run, FUXA **Line** | One E-stop chain reaches **every** PLC: all four E-stop segments in the header turn red (*E-STOP*), everything off at once on all four machines, the oven blower too (*master enable, like an MCR*). State **Stopped**, not Fault. After release: **Start** for the filler, the syrup room, the labeler **and** the packer (picker) – the half-filled bottle is topped up to 500 ml. *One red segment alone would be a wiring fault; a grey "no link" segment is a lost PLC, not an E-stop.* |
| 14 | 1 min | Filler: mode **Manual**, **Filler** view | The jog buttons appear only in Manual. Hold **C1** (moves only while held). Hold **Fill** with no bottle at the fill station: nothing happens (*interlock*). Back to **Auto**, **Start**. |
| 15 | 0.5 min | (Optional) OpenPLC editor | One rung, e.g. the syrup room's overflow alarm (`MixLevel ≥ MixMax OR MixHighHigh OR BufferLevel ≥ BufferMax`), the labeler's glue hysteresis, the packer's blower run-on (TOF) and its wrap bar > film feed > knife lock-out, or the filler's fill interlock. *Ladder is the main language; every rung was tested over Modbus.* |
| 16 | 0.5 min | – | Wrap-up: built = filler, syrup room, labeler and packer (ladder, simulator, HMI, one closed loop over four PLCs); stretch goal left = the blow moulder (grey on the Line view; the palletizer is outside the project). |

Spare scenarios if there are questions:
- filler: `no_product` (Starved, no alarm, bottle topped up), `slow_fill` (`Alm_FillTimeout` after 10 s), `heartbeat_off` (`Alm_CommLost` after 3 s), `gaps` (needs an empty line, see below);
- syrup room: `low_syrup` (Starved + yellow warning `Alm_LowSyrup`, continues by itself after the refill – takes about two batches), `over_pressure` (CO2 valve stuck open, `Alm_OverPressure` at 6 bar), `cooling_failure` and `pump_failure` (each needs its 60 s timeout), `buffer_full` (Blocked in WAIT_BUFFER, continues when the filler has used product);
- labeler: `roll_empty` (yellow *roll low*, then *roll empty*: Starved, no FAULT, continues after the new roll), `glue_refill` (*glue low* warning, cold glue: WARM_UP after the bottle, no FAULT), `bell_stuck` and `gate_jam` (`Alm_PocketJam`, Reset + Start), `heater_stuck_on` (`Alm_GlueOverTemp` at 200 °C, Reset only once it has cooled below 200 °C), `heater_failed` (needs its 120 s timeout);
- packer: `film_empty` (yellow *film low*, then *film empty*: Starved, no FAULT, continues after the new roll), `film_torn` (`Alm_FilmFault` after 10 s in FEED), `pusher_stuck` (`Alm_PackJam` after 3 s), `wrap_bar_stuck` (`Alm_WrapTimeout` after 5 s), `blower_failed` (`Alm_AirflowLost` after 3 s, the heater already off by its interlock), `pack_stuck_in_oven` (`Alm_OvenJam` after 20 s; Reset also zeroes *packs in oven*), `oven_heater_stuck_on` (`Alm_OvenOverTemp` at 230 °C, the blower runs on 30 s, Reset only below 230 °C), `oven_heater_failed` (needs its 120 s timeout).

## 3. Avoid during the demo

- **Running a second scenario before the first is done:** the panel has one slot; the first one stops where it was. If the palletizer stays stopped (`palletizer_stopped` replaced): tab `4 Packer`, switch **Palletizer running** ON.
- **`packer_stopped` / `labeler_stopped`:** not in the panel with the real packer / labeler (they stop the stand-ins of `--no-packer` / `--no-labeler`). Use `palletizer_stopped`.
- **Slow Reset after a packer or labeler FAULT:** a FAULT stops that machine's infeed conveyor (C3 / C2) at once, but its full sensor sits one slot further in, so the machine upstream does not see it as full: its next bottle hits the one standing at the entry (labeler `Alm_PocketJam`; the filler pushes bottles off C2). Have the machine's screen open before **Run** and press **Reset**, **Start** the moment the panel says so (about one cycle: labeler ~5 s, filler ~7 s). Open issue I18 in `roadmap.md`.
- **Restarting the simulator with a partly collected group on the packer table:** the packer PLC keeps its group count (it is cleared only after a push), the new simulator starts with an empty table, so the first pack is pushed short (the simulator logs *pushed with N bottles, not 6*). Harmless; it is right again from the next group.
- **Packer in Manual or Stop mode:** the oven heats only in Auto; back in Auto it warms up again (about a minute, WARM_UP) before the next pack.
- **Restarting the simulator in the middle of a batch:** the syrup PLC remembers a dosed batch (`Batch_Dosed`), the new simulator starts with an empty mixing tank, and the batch cannot finish. Before stopping the simulator, let the batch end and press **Stop** for the syrup room (IDLE). Recovery if it happened: Manual, water pump in pulses under 10 s to about 590 L, then Auto + Start. (A restart also starts the glue and the oven cold: the labeler and the packer warm up again, about a minute.)
- **Syrup scenarios wait for their step:** `level_sensor_stuck` and `pump_failure` start at DOSE_WATER, `cooling_failure` at COOL, `over_pressure` at CARBONATE. A new batch starts only when the buffer is below *New batch below* (default 800 L); run them right after `buffer_starved`, or expect a wait.
- **Manual Door and long manual Fill (filler):** known gaps (`docs/filler/ladder-roadmap.md`, "Change: manual interlocks for door and fill", open). In step 12 use only C1 and Fill without a bottle.
- **Holding a manual button > 10 s:** the jog watchdog ignores it until it is released. Correct, but confusing if unexplained.
- **`gaps` on a full line:** nothing visible happens. First set Supply /min to `0`, wait until the filler is yellow (Starved), then Run; set it back to `30` afterwards.
- **Supply paused ON:** added bottles are queued but never placed.

## 4. If something goes wrong

| Symptom | Fix |
|---|---|
| Bottles stand on C1, filler empty, state Stopped | Start was not pressed in Auto: picker **Filler**, **Auto**, **Start**. |
| Syrup room grey, buffer falling, filler soon Starved | Syrup room not started: picker **Syrup**, **Auto**, **Start**. |
| C2 full, filler orange (Blocked), labeler grey | Labeler not started (it drives C2): picker **Labeler**, **Auto**, **Start**; it warms up first. |
| C3 full, labeler orange (Blocked), packer grey | Packer not started (it drives C3): picker **Packer**, **Auto**, **Start**; it heats its oven first (about a minute). |
| Packer stays in WARM_UP, red after 2 min (`Alm_OvenHeatTimeout`) | *Oven heater failed* switched ON in tab `4 Packer`: switch it OFF, **Reset**, **Start**. |
| Labeler stays in WARM_UP, red after 2 min (`Alm_GlueHeatTimeout`) | Heater failed switched ON in tab `3 Labeler`: switch it OFF, **Reset**, **Start**. |
| Red alarm chips right after starting the simulator | `Alm_CommLost` from the restart, on all four machines: **Ack**, **Reset** per machine, **Start** per machine. |
| Machine stays red after Reset (other cases) | The cause is still there (panel switch ON: E-stop, a syrup, labeler or packer fault, fill flow < 50, glue still ≥ 200 °C, oven still ≥ 230 °C): fix it in the panel, then Reset + Start. |
| A click in FUXA did nothing | About 1–2 % of FUXA's writes time out (issue I16): check the header (state, mode) and press again. |
| Header: *PLC LOST* on a machine chip, grey *no link* E-stop segment | `uv run python tests/demo_check.py`: D2 *Modbus server OFF* → upload that PLC from the Editor; container down → `docker compose up -d`. |
| Trends empty | No data yet (wait one batch) or the page was opened before FUXA reconnected: reload the page. |
| Anything else | Stop the simulator (`q`, after **Stop** for the syrup room at the end of a batch), run `tests/demo_check.py`, follow the printed fix, start again from section 1 step 3. |
